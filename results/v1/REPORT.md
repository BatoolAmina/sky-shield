## Key findings (computed)

- Best model family on the held-out test seeds: **xgboost** (macro-F1 0.9693); runner-up lightgbm (0.9690).
- Primary vs lightgbm: macro-F1 difference -0.0007 (95% CI -0.0021 to +0.0009); the seed-cluster bootstrap interval includes 0, so the difference is **not clearly significant**. (McNemar p = 0.5495 treats windows as independent and is therefore optimistic; trust the bootstrap.)
- Primary vs logreg: macro-F1 difference +0.0182 (95% CI +0.0121 to +0.0247); the seed-cluster bootstrap interval excludes 0. (McNemar p = 0.0000 treats windows as independent and is therefore optimistic; trust the bootstrap.)
- Primary vs mlp: macro-F1 difference +0.0091 (95% CI +0.0049 to +0.0135); the seed-cluster bootstrap interval excludes 0. (McNemar p = 0.0000 treats windows as independent and is therefore optimistic; trust the bootstrap.)
- Primary vs random_forest: macro-F1 difference +0.0023 (95% CI -0.0009 to +0.0059); the interval's lower bound is within 0.001 of zero, so the difference is **borderline**. (McNemar p = 0.0092 treats windows as independent and is therefore optimistic; trust the bootstrap.)
- Primary vs xgboost: macro-F1 difference -0.0010 (95% CI -0.0021 to +0.0003); the seed-cluster bootstrap interval includes 0, so the difference is **not clearly significant**. (McNemar p = 0.0478 treats windows as independent and is therefore optimistic; trust the bootstrap.)
- Distribution shift costs the primary model 0.058 macro-F1 (0.968 -> 0.910); threat recall at the chosen threshold goes 0.996 -> 0.990 while the false-alarm rate rises 0.046 -> 0.105.
- Loss of the RF sensor is the most damaging single failure tested: macro-F1 0.968 -> 0.847 and threat recall 0.987 -> 0.755 (the model leans on RF emission). Loss of EO costs only 0.002 macro-F1; 8x clutter costs 0.002; 3x noise costs 0.043; a 40% radar outage costs 0.014.
- Speed shifts hurt in both directions (0.7x: 0.923, 1.5x: 0.913 macro-F1) because the classes are partly defined by speed ranges the model learned.
- Young tracks are harder: macro-F1 0.904 for tracks aged <= 10 s vs 0.981 for tracks older than 40 s.
- Largest drop among the ablation variants on test: **kinematics + geometry only** (+0.149 macro-F1), then radar-only (no fusion group) (+0.071).
- Tracker/window ablation (test macro-F1): kalman, 15 s window (primary) 0.9683; alpha-beta tracker, 15 s 0.9604; kalman, 8 s window 0.9568; kalman, 25 s window 0.9744.
- Unknown-class detection is **weak**: best detector is entropy with mean leave-one-class-out AUROC 0.694 (0.5 = chance) and TPR 0.381 at 5% FPR. Held-out classes overlap with known ones, so they are often confidently assigned to a known class.
- Priority ranking vs oracle (test, top-1 hit rate): rule-based 0.535, fitted 0.584, classifier probability alone 0.475, closest-first 0.449, random 0.219. The ranking is far from the oracle: it is a decision aid, not an arbiter.
- Explanation faithfulness: removing the SHAP top-3 features flips 69.8% of predictions vs 10.7% for random features, so the mentor's stated reasons are causally relevant to the model. Stability of global importance across a retrained model: Spearman 0.982.
- Adaptive adversary: lowest final regret was **UCB1** (single regime change) and **Thompson (stationary)** (fast switching). Discounted Thompson sampling (gamma 0.95) had regret 58.6 / 51.3 vs 42.4 / 33.6 for stationary Thompson sampling, so **discounting did not help in these experiments**. In the measured success table the best tactic is the same (saturation) against 3 of the 4 defences, so the optimum barely moves between regimes; a stronger non-stationarity test would need defences with different best tactics.

## 14. What was NOT executed in this run

- GPU training: no GPU/PyTorch in the environment that produced this report. The optional sequence model (`ml/src/skyshield_ml/seq_torch.py`) and LightGBM/XGBoost challengers are included in the code and are picked up automatically when installed, but their results are not in this report.
- The MERN web application could not be installed or run in this offline environment. Its logic modules, REST layer and session manager are unit-tested; the Express/ws/Mongo adapters and the Vite build have not been executed here.
- Real-sensor datasets (DroneRF etc.): not downloadable here. The RF module is implemented and self-tested on a synthetic stand-in only; no real-data result is reported.
